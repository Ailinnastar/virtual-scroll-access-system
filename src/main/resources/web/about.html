YOUR FIRST VISIT

Make yourself at home.

You can explore the library before deciding to join. Here’s how to get started as a guest.

  1. 01

    Browse the collection

    Open Browse Scrolls to see the files currently shared in the library. You don’t need to register or log in.

  2. 02

    Find a scroll

    Search by scroll name or scroll ID. Use Clear to remove your search and return to the full collection.

  3. 03

    Take a closer look

    Read the preview shown on each scroll card. Text scrolls show their first five lines; binary files show a file-size summary.
